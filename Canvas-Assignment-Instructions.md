# How to Complete Your Python Practice Notebooks

For each assigned unit, follow these steps:

1. **Read the assigned chapter(s)** in Melanie Walsh's *Introduction to Cultural Analytics & Python* (linked on Canvas / in the course repository).

2. **Find the template notebook** in your course repository: `1-[LastName]-Template-Notebook.ipynb`. This file always sits at the top of your folder.

3. **Make a copy of it.** In Finder (Mac) or File Explorer (Windows), duplicate the template — do not edit the original.

4. **Rename your copy** using this format:
   `[LastName]-##-UnitTopic-Notebook.ipynb`
   *Example:* `Proctor-02-Python-Basics-Notebook.ipynb`

5. **Open your renamed copy in Jupyter** and work through the chapter. As you go:
   - Give each concrete step its own cell.
   - Add a Markdown cell above each code cell explaining what you're about to do and why — write it *before* you write the code.
   - Use `#` comments inside code cells for line-level notes.
   - Log anything that breaks in the **Failure Log** section at the bottom, even if you never fixed it.

   (See the Markdown Cheatsheet in the repository if you need a refresher on formatting Markdown cells.)

6. **Save your notebook** when you're done.

7. **Export an HTML copy:** in Jupyter, go to **File → Save and Export Notebook As → HTML**.

8. **Submit both files** to the assignment on Canvas:
   - Your `.ipynb` file
   - Your exported `.html` file

Submitting both lets your instructor open your work directly in SpeedGrader (via the HTML file) while keeping the original working notebook (the `.ipynb`) on file.
